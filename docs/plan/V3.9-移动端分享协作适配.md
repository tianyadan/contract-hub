## 1. 背景与目标

### 1.1 问题

| 现象 | 原因 |
|------|------|
| 手机打开分享页纸面溢出、难以操作 | 纸面按 PC 最大宽度（约 760px）渲染，未适配可视宽度 |
| 保存 / 确认按钮需滚到右侧栏底部 | 桌面双栏布局，操作区在侧栏，手机端被挤到文档下方且不便触达 |
| 顶栏信息过密 | 品牌长文案、分享提示、最近保存挤在一行 |

### 1.2 目标

| 目标 | 验收标准 |
|------|----------|
| 纸面适配 | iPhone / Android 竖屏（≤767px）下，合同纸面完整落入可视宽度，可翻页、选中编辑 |
| 导出不受损 | 手机端导出 PDF 清晰度与 PC 一致（不因屏幕缩放降低导出分辨率） |
| 单手操作 | 保存 / 确认 / 导出固定在屏幕底部，拇指可及 |
| 信息分层 | 版本记录 / 确认记录以 Tabs 呈现，不与编辑区抢首屏 |

### 1.3 范围

| 纳入 | 不纳入（本期） |
|------|----------------|
| 外部分享页 `SharePage` 移动布局 | 原生 App / 小程序 |
| `DocumentEditor` 纸面 fit 缩放 | 模板池管理后台全面移动化 |
| 合同详情页基础窄屏样式 | OT/CRDT 实时同屏光标 |
| 冲突弹窗、变更退出浮层窄屏 | 平板横屏专项设计稿 |

## 2. 技术方案要点

### 2.1 断点

| 断点 | 用途 |
|------|------|
| `≤767px` | **手机**：分享页移动布局、底部 Dock、编辑器 padding 压缩 |
| `≤991px` | 平板：Ant `Col` 已自动单列堆叠 |

前端 Hook：`frontend/src/hooks/useMediaQuery.ts` → `useIsMobile()`（`max-width: 767px`）。

### 2.2 纸面缩放策略（关键）

**不要**用缩小后的 `computePaperLayout(maxWidth=手机宽)` 去做分页测量——会导致：

1. 分页结果随设备变化；
2. 导出宿主同样变小，PDF 像素不足。

**采用 CSS `transform: scale`：**

1. 分页 / 测量 / 导出仍按 `MAX_PAPER_WIDTH`（760）计算布局；
2. 用 `ResizeObserver` 监听 `.doc-editor__pages` 宽度；
3. `fitScale = min(1, containerWidth / pageWidthPx)`；
4. 显示层外包 `.doc-editor__page-fit` / `.doc-editor__page-fit-inner` 做缩放。

相关代码：

- `DocumentEditor.tsx`：`fitScale` + `pagesHostRef`
- `doc-editor.css`：`.doc-editor__page-fit*`

### 2.3 分享页信息架构（手机）

```
┌──────── sticky topbar（精简品牌 + 权限 Tag + 头像）──┐
│ 合同标题 / 元信息                                       │
│ 确认状态 Banner / 过期提醒                               │
│ DocumentEditor（纸面 fit）                               │
│ Tabs：版本记录 | 确认记录                                │
└──────────────────────────────────────────────────────────┘
┌──────── fixed bottom Dock（安全区）──────────────────────┐
│ 协作者名 · 权限 Tag                                      │
│ [保存版本] [确认合同] [导出 PDF]                         │
└──────────────────────────────────────────────────────────┘
```

桌面（`>767px`）仍为左编辑 + 右侧三卡片（版本 / 操作 / 确认），行为不变。

### 2.4 触控与安全区

- 底部 Dock：`padding-bottom: env(safe-area-inset-bottom)`，页面 `padding-bottom` 预留 Dock 高度，避免内容被挡。
- 翻页按钮：手机端最小约 48×48 触控热区（`doc-editor.css`）。
- `index.html` viewport：`viewport-fit=cover`，便于刘海屏安全区生效。

## 7. 局域网访问（开发机）

前端 Vite 已配置 `server.host: true`，本机执行 `npm run dev` 后可用：

| 入口 | 地址示例 |
|------|----------|
| 本机 | `http://localhost:5173` |
| 局域网（手机） | `http://172.20.10.2:5173` |

说明：

1. 手机与电脑须在同一局域网（或同一热点）。
2. `/api` 由 Vite 代理到本机 `127.0.0.1:8080`，手机无需直连后端端口。
3. 若 PDF 验真二维码扫不开，请将后端环境变量改为：
   `PUBLIC_WEB_ORIGIN=http://172.20.10.2:5173` 并重启 Go 服务。
4. macOS 若无法访问，检查「系统设置 → 网络 / 防火墙」是否放行 Node。
