# V2 改造计划（已废止）

> **状态：已废止（2026-08-28）**  
> 文档层相关目标（DOCX 保真预览、RenderWithTemplate 导出、结构化 JSON 块级 diff 等）经评估**不可行**，不再实施。

## 废止说明

V2 中以下内容**全部废止**：

- 「导入 DOCX = 在线展示 = 导出 DOCX」的保真路线
- `docx-preview` 作为主展示 + `DocumentEditor` 结构化编辑双轨
- Python `docx_renderer` / `render_docx_with_template` 导出
- 块级 `docx_diff` 作为用户主审查手段
- OnlyOffice 等重型文档服务器备选方案

## 仍然有效（业务层）

以下 V2 已落地能力**继续保留**，并入 V3：

- 客户管理（`customer`）
- 合同模板池（`contract_template`）
- 从模板为客户创建合同（OSS CopyObject）
- 合同详情协作：版本、分享、确认、Presence
- `sql/migrate_v2.sql` 数据模型
