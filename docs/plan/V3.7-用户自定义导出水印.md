## 1. 背景与目标

### 1.1 需求

| # | 需求 | 说明 |
|---|------|------|
| R1 | 新开菜单「合同设置」 | 侧栏独立入口，内含「导出水印」配置 |
| R2 | 导出水印开关 | 开启后，合同编辑页纸面全页展示水印（防伪） |
| R3 | 自定义水印内容 | 用户可编辑文案并保存，按登录用户持久化 |
| R4 | 导出一致 | 开启时，导出 PDF / PNG / 确认终稿截图均叠加同一水印 |

### 1.2 非目标

| 项 | 说明 |
|----|------|
| 按合同单独配置水印 | 本期为**用户级**设置，非合同级 |
| 外部分享页配置水印 | 分享页无登录态；本期不对外部协作者暴露配置入口 |
| 图片水印 / 复杂排版 | 仅文字平铺旋转水印 |
| 替换终稿二维码 | 二维码验真保留；自定义水印与草稿「草稿」水印并存策略见 §3.4 |

### 1.3 验收标准

| 目标 | 标准 |
|------|------|
| 配置可保存 | 刷新后开关与文案仍在 |
| 编辑页可见 | 开关打开且文案非空时，当前纸面与导出宿主页均可见全页水印 |
| 开关关闭 | 编辑页与导出均无自定义水印 |
| 导出 | PDF 草稿/终稿、确认归档截图均带自定义水印（开启时） |

---

## 2. 用户流程

```text
侧栏「合同设置」→「导出水印」
  → 打开开关、填写文案（如公司名 / 姓名）→ 保存
  → 进入合同编辑页：纸面全页平铺半透明斜向水印
  → 导出 PDF / 确认合同：截图页同样带水印
```

## 3. 方案设计

### 3.1 数据模型

表 `user_watermark_setting`（用户一对一）：

| 字段 | 类型 | 说明 |
|------|------|------|
| user_id | BIGINT PK | 用户 ID |
| enabled | TINYINT | 0 关 1 开 |
| content | VARCHAR(64) | 水印文案（trim 后） |
| create_time | DATETIME | |
| update_time | DATETIME | |

默认：无记录视为 `enabled=0, content=''`。

### 3.2 API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/settings/watermark` | 获取当前用户水印设置 |
| PUT | `/api/settings/watermark` | 保存 `{ enabled, content }` |

校验：`content` 最长 64；开启时 `content` 不能为空。

### 3.3 前端菜单与路由

| 项 | 值 |
|----|-----|
| 侧栏 | 「系统设置」改为「合同设置」，子菜单「导出水印」 |
| 路由 | `/settings/watermark` |
| `/settings` | 重定向到 `/settings/watermark` |

### 3.4 展示与导出

| 场景 | 行为 |
|------|------|
| 合同编辑 `DocumentEditor` | `enabled && content` 时在 `.doc-page` 叠加全页平铺水印（`pointer-events: none`） |
| 导出 PNG/PDF | 截图前临时叠加相同结构；结束后移除 |
| 草稿水印「草稿」 | 开启自定义水印时仍可叠加「草稿」字样（右下或沿用原居中大字）；自定义水印为平铺底纹 |
| 外部分享页 | 本期不加载用户水印设置（无 JWT）；后续可按合同 owner 下发 |

### 3.5 视觉

- 斜向约 -28°～-32°
- 半透明深灰字（约 `rgba(0,0,0,0.08)`～`0.12`）
- 平铺覆盖整页，防裁切窥视
